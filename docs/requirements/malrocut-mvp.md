# Malrocut AI MVP 요구사항 정의서

## 1. 개요
프롬프트 기반 동영상 자동 편집 웹 서비스 '말로컷 AI'의 MVP 버전 요구사항을 정의합니다.

## 2. 주요 기능 명세
### 2.1 파일 입출력
- **입력**: MP4 포맷의 동영상 업로드 (썸네일용 이미지 업로드 옵션)
- **출력**: 편집된 동영상(`edited_video.mp4`), 자막 파일(`subtitle.srt`), 썸네일 이미지(`thumbnail.jpg`) 다운로드 제공

### 2.2 자막 및 음성 처리
- **기존 자막 제거**: 영상 내 하드코딩된 기존 자막 영역을 감지하고 블러 또는 크롭 등으로 처리하여 가림/제거
- **대본 추출**: 오디오를 인식하여 텍스트 대본(Transcript) 추출
- **대본 수정**: 추출된 대본을 사용자가 텍스트 에디터에서 수정 가능
- **새 자막 생성**: 수정된 대본 또는 프롬프트를 바탕으로 새로운 스타일의 자막 합성
- **다국어 번역 및 재구성**: 한국어, 영어, 일본어 자막 지원 및 문장 맥락에 맞는 재구성

### 2.3 영상 편집 연출
- **컷 편집**: 무음 구간 제거 및 텍스트 기반 컷 삭제 기능
- **장면 재배치**: 프롬프트 지시에 따라 특정 컷의 순서 변경
- **화면 연출**:
  - 얼굴 인식 기반 중앙 정렬 (Auto-framing)
  - 특정 컷 화면 확대 (Zoom-in) 적용
- **색감 보정**: 영상 전반적인 컬러 그레이딩(LUT 또는 AI 기반 보정) 적용

### 2.4 썸네일 기능
- 업로드된 이미지를 활용하거나 영상 내 주요 장면을 추출하여 썸네일 자동 생성 (텍스트 레이어 합성 포함)

## 3. 작동 프로세스 (기본 변화 세트)
사용자가 원본 영상을 올리고 특정 프롬프트를 입력하면 아래 과정이 자동 수행되어야 합니다.
1. 기존 자막 영역 처리 (제거/가림)
2. 음성 인식 및 새 자막 생성 (언어 설정에 따른 번역 및 재구성)
3. 장면 순서 재배치 및 무의미한 컷 제거
4. 얼굴 중앙 정렬 및 화면 확대 효과 추가
5. 전체 영상 색감 보정
6. 썸네일 이미지 생성 및 결과물 제공

## 4. MVP 제외 항목 (Out of Scope)
- 음성 클론 (사용자 목소리 학습 및 TTS)
- 립싱크 맞춤 보정
- 화려한 화면 전환(고급 트랜지션) 효과
- 데스크톱 캡컷(CapCut) 프로젝트 파일로 내보내기 연동
- YouTube 등 플랫폼 직접 자동 업로드 기능
- 모바일 네이티브 앱 개발 (반응형 웹으로만 대응)
- 팀 및 워크스페이스 기반 협업 기능
- 손상된 배경을 완벽하게 채우는 고수준 AI 인페인팅 (Inpainting)
- 롱폼 영상에서 숏폼(Shorts)을 다수 자동 추출하는 기능
